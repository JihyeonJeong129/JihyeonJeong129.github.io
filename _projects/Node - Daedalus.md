## Node - Daedalus: FPGA Test Server Overview
This project introduces **Node - Daedalus**, the only non-enterprise grade server among the current infrastructure.  
It is primarily dedicated to **FPGA system testing**, especially for experiments with the Xilinx ZYNQ-7000 platform.

- **Hardware**:  
  - Custom-built PC (non-enterprise grade)  
  - CPU: Intel Core i5-4670  
  - RAM: 8 GB  
  - Storage: 2 TB HDD  

- **Purpose**:  
  - Configured for **FPGA development and testing**  
  - Dedicated to **Xilinx ZYNQ-7000 board** experiments
