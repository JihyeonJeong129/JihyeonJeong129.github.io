## 프로그램 개요
**OMRON PLC** 기반 이차전지 설비 제어 **PLC 이론 + 실습** 프로그램입니다. 래더 로직, 디바이스 I/O 매핑, 안전 인터록, 실 설비 시나리오 디버깅 등을 다룹니다.

- 기간: 4주 (2025 여름)
- 하드웨어: OMRON PLC (CJ / CP / NX 시리즈), 디지털 I/O 모듈, 센서 / 액추에이터
- 소프트웨어: CX-Programmer / Sysmac Studio
- 결과물: 안전한 시작·정지 / 알람 / 인터록을 갖춘 **셀 핸들링 미니 데모 라인**

---

### 하이라이트
컨트롤 패널 배선, 래더 로직 디버깅, 안전 인터록 검증을 직접 수행했습니다.

### 구현 항목
시작 / 정지 시퀀스, 비상 정지, 알람 래치, 리미트 스위치 기반 셀 핸들링 루틴.  
**I/O 매핑 / 타이머·카운터 / 엣지 검출 / 결함 복구** 흐름을 실습했습니다.
