Node - RaspberryPi

Raspberry Pi 보드로 구성했던 과거 NAS 서버 프로젝트

개요

Node - RaspberryPi는 홈랩을 시작하게 된 초기 NAS 실험입니다. Raspberry Pi 3 B+와 Raspberry Pi 4를 이용해 저전력 파일 서버를 구성했습니다.

문제와 목표

저비용 장비로 NAS를 운영할 수 있는지 확인하고, Linux 기반 저장소 운영의 기본을 익히는 것이 목표였습니다.

내 역할

  • OpenMediaVault를 설치하고 파일 공유 환경을 구성했습니다.
  • 외장 HDD를 연결해 NAS 형태로 운영했습니다.
  • 이후 Hades로 이전하기 전까지 저장소 운영 경험을 쌓았습니다.

접근과 이슈

Raspberry Pi는 시작하기 쉽지만 I/O 성능과 장기 안정성에는 한계가 있었습니다. 이 경험을 통해 더 안정적인 서버형 저장소 노드가 필요하다는 판단을 하게 되었습니다.

결과

  • 저전력 NAS 실험을 통해 Linux 저장소 관리의 기초를 익혔습니다.
  • 이후 Hades 기반 홈랩 저장소 구조로 확장하는 출발점이 되었습니다.
